# 独立搜索窗口设计

## 目标

为 Prime Files 增加一个独立的全盘搜索窗口，复用现有索引服务，提供接近 Everything 的常驻搜索体验。窗口与文件浏览窗口独立存在，可通过主程序快捷入口打开。

## 第一版范围

- 顶部实时搜索输入框，输入变化后取消旧查询并执行新查询。
- 中央结果表格：名称、路径、类型、大小、修改时间。
- 双击文件或目录：文件由系统打开，目录在资源管理器中打开。
- 右键菜单：打开、在资源管理器中显示。
- 底部显示命中数量、查询耗时和索引不可用/结果截断状态。
- 复用 `nohrs-indexer` 的 SEARCH 协议；服务不可用时显示明确状态，不重复建立索引。
- 窗口使用 Prime Files 当前主题，固定大小并可移动、可调整大小。

## 暂不纳入

分页、百万级结果总数、复杂列排序、正则/高级筛选编辑器和独立索引缓存。现有查询上限作为第一版结果上限，并在界面中提示截断。

## 架构与数据流

`nohrs` 应用层新增打开搜索窗口的入口；`nohrs-pages` 新增 `SearchWindow` 视图与窗口选项。视图持有输入状态、结果快照、查询序号和当前任务。每次输入递增序号，后台线程调用索引客户端；返回结果只有序号仍是最新时才应用，保证慢查询不会覆盖新查询。结果行只保存索引返回的路径、目录标记、大小和修改时间，不加载全盘目录。

## 错误处理

索引服务未运行、连接失败或协议错误显示在底部状态栏；结果清空但窗口保持可用。路径已被删除时打开操作显示失败通知。空查询显示引导文案，不执行全盘查询。

## 验证

为查询结果转换和过期响应丢弃添加单元测试；运行 `cargo test -p nohrs-pages --lib`、`cargo check -p nohrs` 和 `cargo build -p nohrs`。
